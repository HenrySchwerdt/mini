# M0112: Owning value in an escaping lambda

<span class="diag-badge error">error</span>

## What it means

A lambda that is not inlined and is not a thread boundary captures an owning value. Closures as owners (move capture) are not supported yet.

## Minimal failing example

From the test corpus: [`compiler/testdata/memory/capture_escaping_lambda.kt`](https://github.com/HenrySchwerdt/mini/blob/main/compiler/testdata/memory/capture_escaping_lambda.kt). The corpus expects `13:12: M0112` (the `^` comment in the source marks the column).

```kotlin
// REJECT M0112: an owned value captured by a lambda that escapes. Spec 5.5, 7.12
@file:MemoryMode(Mode.Strict)

package memory.capture_escaping_lambda

import mini.memory.*

class Box(val v: Int)

context(h: Heap)
fun later(): () -> Int {
    val b = Box(3)
    return { b.v }
//         ^ M0112
}

fun main() {
    context(Heap()) { println(later()()) }
}
```

## Compiler output

Generated by running `./minic check compiler/testdata/memory/capture_escaping_lambda.kt` (exit status 1).

```text
$ ./minic check compiler/testdata/memory/capture_escaping_lambda.kt
error[M0112]: owned `b` is captured by a lambda that escapes
  --> compiler/testdata/memory/capture_escaping_lambda.kt:13:12   captured here
   13 |     return { b.v }
      |            ^
  help: pass the value as a parameter, or read what you need before creating the lambda
```

## How to fix

Pass the value to the code that needs it as an explicit parameter, or read the data you need (`b.v`) before creating the lambda and capture that instead.
