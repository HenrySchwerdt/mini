# M0111: Invalid ownership annotation

<span class="diag-badge error">error</span>

## What it means

`@Owned` is placed on a type that has no ownership (primitives, `String`, Managed classes), `@Owned` and `@Borrowed` are combined, or `@Borrowed` contradicts an owning return.

## Minimal failing example

From the test corpus: [`compiler/testdata/memory/annotation_misuse.kt`](https://github.com/HenrySchwerdt/mini/blob/main/compiler/testdata/memory/annotation_misuse.kt). The corpus expects `8:14: M0111` (the `^` comment in the source marks the column).

```kotlin check=M0111
// REJECT M0111: @Owned on a type that has no ownership (Int). Spec 4.4, 7.11
@file:MemoryMode(Mode.Strict)

package memory.annotation_misuse

import mini.memory.*

fun twice(x: @Owned Int): Int = x * 2
//           ^ M0111

fun main() {
    println(twice(4))
}
```

## How to fix

Remove the annotation.
