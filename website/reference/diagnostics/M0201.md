# M0201: Allocation moved to the stack

<span class="diag-badge info">info</span> <span class="diag-badge planned">planned, not implemented</span>

## What it means

An informational note that an allocation does not escape and lives on the stack. It is specified in docs/memory-model.md (shown only with `-Minfo`), but no `M0201` exists in the compiler yet.

## Example

There is no example: this code is not emitted by the compiler yet, so there is no corpus program and no compiler output to show.

## How to fix

Nothing to fix: it is not an error and never changes whether a program is accepted.
