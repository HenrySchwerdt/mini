# M0203: Large object on the stack

<span class="diag-badge warning">warning</span> <span class="diag-badge planned">planned, not implemented</span>

## What it means

A warning for objects larger than a size threshold (default 64 KB in the spec) that would be placed on the stack. Specified in docs/memory-model.md, not implemented in the compiler yet (it belongs to the escape-analysis work).

## Example

There is no example: this code is not emitted by the compiler yet, so there is no corpus program and no compiler output to show.
