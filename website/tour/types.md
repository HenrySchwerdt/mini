## Notes

- `data class` members (`toString`, `equals`, `hashCode`, `copy`, `componentN`) are generated by the Kotlin frontend and compiled like hand-written code.
- Enum entries live in a hidden singleton created on first use. `entries`, `values()`, `valueOf()`, `name`, `ordinal` and `compareTo` work, also for entries with bodies.
- `when` over a sealed class or enum needs no `else`. The compiler checks exhaustiveness (that is K2's job) and the generated code uses type tests (`is`).
