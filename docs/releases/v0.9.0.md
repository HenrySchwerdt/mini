Mini 0.9.0 brings the LLVM API compiler and native REPL to experimental Windows x64 packages, and simplifies installation with a standalone PowerShell release installer.

## Windows LLVM API and REPL

The Windows ZIP includes statically linked LLVM 18. `mini build`, `mini run` and `mini test` use the LLVM API by default; `--backend c` selects the C fallback. `mini repl` keeps declarations and values across inputs without replaying previous cells. No external LLVM SDK is needed to run the packaged compiler. Building native programs still requires Visual Studio's LLVM Clang toolset and Windows SDK.

Native Windows checks cover byte-identical stage 2/3 C, MIR, LLVM IR and object output; Unicode source and output paths; required PE runtime exports; JIT execution; session ownership and rollback; installed API/C backends; and REPL execution. The packaged LLVM license is included alongside Mini's license and notice.

Windows remains experimental. Threads and Windows sanitizer parity are not provided. The documented REPL input/runtime-exception limits and LLVM API debug-symbol limitation remain in effect. The Unix `minic` shell wrapper is not included in the Windows package; use `mini.exe` for projects.

## Installation

Windows x64, in PowerShell 7:

```powershell
curl.exe -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.ps1 -o install-mini.ps1 && pwsh -File .\install-mini.ps1
```

The installer verifies the release ZIP against `SHA256SUMS`, checks its paths and payload, and installs into a new directory. It refuses to overwrite an existing installation and leaves persistent PATH settings unchanged. The website's main page now shows both Windows and Unix setup commands.

Linux and macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.sh | sh
```

The C source installer remains available; selecting `-Backend llvm-api` builds the Windows API compiler and REPL from source. Release archives are provided for Linux x64/arm64, macOS arm64 and Windows x64, together with the portable C bootstrap seed and `SHA256SUMS`.
