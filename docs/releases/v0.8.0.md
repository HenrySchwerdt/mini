Mini 0.8.0 adds experimental native Windows x64 support and includes the measured compiler/runtime improvements developed since 0.7.0.

## Windows x64 (experimental)

The Windows package provides `mini.exe`, `minic-native.exe`, the runtime and standard-library sources. `mini new`, `build`, `run`, `test` and `check` use the C backend. Native Windows tests cover self-compilation with identical stage 2/3 C and MIR, Unicode paths and arguments, subprocess quoting, large captured output, environment/working-directory isolation and compiler failures.

Windows builds require Visual Studio 2022 C++ Build Tools with LLVM Clang and the Windows SDK. Use Developer PowerShell and PowerShell 7. The install page documents the PowerShell source installer, which verifies its bootstrap download and refuses to overwrite an existing prefix.

The Windows ZIP is **C-backend only**. Windows LLVM API, REPL, native thread support and sanitizer parity are not included. Linux and macOS retain the LLVM API default, bundled LLVM and `mini repl`; the explicit C fallback remains available.

## Compiler and runtime improvements

* Optimized macOS application links remove unused code, and the packaged macOS compiler drops local symbols while retaining external exports. Debug and bootstrap paths remain separate.
* The compiler avoids empty substitution maps for non-generic classes.
* Reviewed runtime changes reduce allocation/RC overhead in reference arrays, ArrayList and StringBuilder. LLVM string access fast paths retain bounds/null checks and fallback behavior.
* WebAssembly fixtures keep browser-only allocator behavior separate from native compiler checks. Browser programs continue to compile live; only libraries are shipped precompiled.

On the recorded local fixed-input C/MIR self-compilation workload, the combined campaign reduced median wall time by 7.9% and retired instructions by 9.6%, with identical output. These are not complete build/link measurements. The JSON confirmation remained about 1.205 times the fastest tested strict C reference: the broader 1.2x target has **not** been established. See the repository's optimization reports for methods, tradeoffs and rejected experiments.

## Assets and installation

* Linux x64, Linux arm64 and macOS arm64: LLVM API toolchain `.tar.gz` archives.
* Windows x64: experimental C-only `.zip` archive. Extract it to a new directory and add its `bin` directory to a Developer PowerShell session's PATH.
* Portable C bootstrap seed and `SHA256SUMS`.

Unix installation remains:

```sh
curl -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.sh | sh
```

REPL input/runtime-exception limits and the LLVM API debug-symbol limitation documented in 0.7.0 remain in effect.
