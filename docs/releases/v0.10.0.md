Mini 0.10.0 is a language-coverage, performance and size release: 98.3% of the applicable Kotlin box tests now compile and pass natively (5853 of 5953, up from 67.1% at the 0.9.0 baseline), executables are smaller, array-heavy loops are close to Rust, and a round of memory-safety gaps is closed.

## Kotlin conformance

The new harness in `tools/conformance` runs the applicable codegen box tests of JetBrains/kotlin (v2.0.21) through `minic`. Against the 0.9.0-era toolchain (4008 of 5971, 67.12%) eight rounds of fixes reached **5853 of 5953 (98.3%)**, with every round checked test by test for regressions. Remaining failures are 63 compile errors, 15 compiler crashes, about 20 runtime failures and a few timeouts (see `docs/conformance.md`).

Language and library work behind that number: enum bodies and entries, property and builtin references, annotations with arguments, `tailrec` (including `tailrec suspend`), unsigned types, value classes (unboxed, generic), `Byte`/`Short` boxing and arrays, `provideDelegate`, adapted callable references, non-local `break`/`continue`, `CharSequence`, `suspend` inside inline lambdas, `coroutineContext`, and a much larger standard library (Regex engine, `String.format`, sequences, `Random`, `Duration`, `TreeMap`, `kotlin.test`). Coroutines (CPS state machines), `sequence`, `mini.coroutines` and native threads are available without libuv.

## Memory safety

Strict mode gained inferred borrow summaries, borrowing closure captures, anonymous objects, `.mlib` summaries, and a corpus of 111 programs. In Managed mode an audit closed these gaps (`docs/memory-model.md`, "Memory-safety gaps closed"): erased-to-specific conversions are now checked casts (heap pollution throws `ClassCastException` instead of reading foreign layouts), non-null fields read before initialization throw `NullPointerException`, huge array allocations and failed allocations are checked, `list.addAll(list)` terminates, the exception at the end of an uncaught-exception exit no longer leaks, reference-count races between threads are fixed, and local function references no longer escape the Strict checker. A cycle collector and a memory stress suite were added, and the new tests run under AddressSanitizer and LeakSanitizer.

## Performance

* MIR optimizer: inliner, exact-type devirtualization, scalar replacement (escape analysis), internal linkage, unreachable-function pruning, early release of last-use locals.
* Latin-1 strings, reference-count elision across `ArrayList.add`, cheaper cycle collection, a `HashMap` last-key cache, object field reordering to reduce padding.
* Array length caching and bounds-check loop versioning: in the 4-core test VM fannkuch went from 1.31x to 1.04x of Rust's time and spectralnorm from 1.32x to 1.10x. Plain C division for constant divisors.
* Persistent stub cache: parsed standard-library stubs are kept between runs, and inline stub bodies are checked lazily. The REPL hands the JIT only the library code an input reaches.

Mini compared with Rust (`rustc -O`, `codegen-units=1`), median of 7 runs, same session:

| benchmark | Rust s | Mini s | Mini / Rust |
|---|---:|---:|---:|
| fannkuch | 2.27 | 2.35 | 1.04 |
| spectralnorm | 1.29 | 1.42 | 1.10 |
| nbody | 0.94 | 1.24 | 1.31 |
| wordcount | 1.25 | 2.82 | 2.26 |

Earlier baseline ratios for the other four benchmarks: binarytrees 0.88, mandelbrot 0.86, strbuild 1.22, json 1.24. Peak RSS is within 15 percent of Rust. The remaining gaps are explained in `docs/optimization/rust-gap-2026-11.md` (nbody needs escape analysis of object arrays; wordcount needs an unboxed `HashMap<K, Int>` path).

## Executable size

Optimized Linux builds are linked with `--gc-sections,--strip-all`, programs link the cycle collector and arena only when they use them, and the Unicode tables are encoded compactly (26 KB down to 11 KB).

| program | 0.9.0-era | now | Rust, stripped |
|---|---:|---:|---:|
| hello | 27 KB | 14 576 B | 342 520 B |
| collections | 166 984 B | 133 520 B | 397 544 B |
| strings | 135 128 B | 96 656 B | 360 448 B |

Mini executables are 3-23x smaller than stripped Rust. Set `MINIC_KEEP_SYMBOLS=1` (`MINI_KEEP_SYMBOLS=1` for `mini`) to keep the symbol table; `--debug` builds always keep it. `mini build --release` now also compiles with function and data sections and no unwind tables.

## Other changes

The wasm docs site no longer duplicates library helpers in separate-mlib programs, and CI caches the LLVM 18 development packages. Windows packages keep the 0.9.0 behavior (LLVM API and REPL included).

## Installation

Linux and macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.sh | sh
```

Windows x64, in PowerShell 7:

```powershell
curl.exe -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.ps1 -o install-mini.ps1 && pwsh -File .\install-mini.ps1
```

Release archives are provided for Linux x64/arm64, macOS arm64 and Windows x64, together with the portable C bootstrap seed and `SHA256SUMS`.
