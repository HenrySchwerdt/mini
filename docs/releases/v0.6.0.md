Mini 0.6.0 adds precompiled libraries, Float32 tensors, plotting and WebAssembly library exports, plus an interactive digit classifier in the browser.

## Highlights

* **Precompiled libraries.** `minic-native --emit-mlib` and `--lib`, dependency builds through `.mlib`, `mini package`, and a precompiled standard library in the release archives.
* **Float and FloatArray.** Real 32-bit floating-point storage and arithmetic, array accessors, boxing and C interop. `mini.tensor` uses Float32 tensors with BLAS acceleration where available and a Kotlin fallback.
* **Tensor and autograd library.** Broadcasting, matrix multiplication, automatic differentiation, neural-network layers and optimizers. The tensor and plot libraries are available in the browser toolchain.
* **Plotting.** `mini.plot` provides pyplot, Axes and Kotlin DSL APIs, SVG figures, subplots, log scales, tooltips and colormaps. Rich display output appears below notebook and playground cells.
* **WebAssembly libraries.** Export supported functions with `@WasmExport`, build a `wasm-lib` package with `mini build --target wasm32 --lib`, and use the generated JavaScript module and TypeScript declarations. See the [WebAssembly library guide](https://henryschwerdt.github.io/mini/guide/wasm-library).
* **Digit classifier notebook.** Train and compare matrix and `Linear` classifiers, inspect three plot APIs, and try the trained models on drawings. The default experiment is precompiled; successful compilations are cached locally so repeated runs avoid loading the compiler toolchain when possible.
* **Native development workflow.** Compiler unit tests and end-to-end tests run through Mini without Gradle or a JVM. `mini check` checks all project source files. Kotlin cross-checks remain available separately.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/HenrySchwerdt/mini/main/install.sh | sh
mini new hello && cd hello && mini run
```

Release archives contain `mini`, `minic`, the self-hosted compiler, the runtime and the standard library for Linux x64, Linux arm64 and macOS arm64. A portable C bootstrap seed and `SHA256SUMS` are included. A C compiler is required for native builds; the WebAssembly library target additionally needs a WASI-capable clang and wasm-ld.

Try the [digit notebook](https://henryschwerdt.github.io/mini/libraries/digits) or read the [documentation](https://henryschwerdt.github.io/mini/).

## Known gaps

* Windows releases, coroutines and async IO, reflection and JSON support are still planned.
* Strict-mode code generation and the standard library's adoption of the ownership memory model remain in progress.
* The digit experiment downloads a public dataset and needs network access on its first run.
